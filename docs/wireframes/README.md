# Figma Wireframe & Theme Template Guide

This directory contains the complete wireframe set and Figma design system template for **`qiuizez`** to satisfy the **M1 Frontend Prototype** milestone requirements (`Wireframes of the main screens in docs/`).

---

## 1. How to Import Into Figma

### Option A: One-Click All-Screens Canvas (Recommended)
1. Open your Figma canvas or create a new Figma project file.
2. Drag and drop `docs/wireframes/all_screens_wireframe.svg` directly from your file explorer into Figma.
3. Figma will parse every artboard, layer, color fill, and vector shape into editable frames.

### Option B: Import Screen-by-Screen
You can also drag and drop each standalone screen into Figma to create individual page frames:
* **`00_theme_and_design_system.svg`**: Design System tokens, 4-theme color swatches, 3D button states, and the 4 Kahoot touch shape cards.
* **`01_home_join.svg`**: Landing page, Game PIN input field, nickname input, and hero join card.
* **`02_login_register.svg`**: Tabbed authentication card (Sign In / Create Account) and 1-click demo profile switcher.
* **`03_instructor_dashboard.svg`**: Instructor dashboard with quiz counts, active sessions, and quiz cards.
* **`04_quiz_editor.svg`**: Interactive quiz authoring form, question prompt, time limit/point pickers, and 4 colored shape answer cards.
* **`05_host_lobby.svg`**: Projector lobby view with giant 6-digit PIN, connected player roster, 4 balanced team boxes, and randomize wheel button.
* **`06_host_question_active.svg`**: Active gameplay screen with countdown circular timer, prompt, answer distribution, and live team standings.
* **`07_student_gameplay.svg`**: Mobile phone viewport (420×880) with assigned team banner and 4-quadrant tactile touch shape buttons.
* **`08_summary_podium.svg`**: Final game summary with 3D podium (2nd, 1st, 3rd place), confetti particles, and top MVP contributors.
